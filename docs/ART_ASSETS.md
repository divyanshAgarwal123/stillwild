# Original environment artwork

Both backplates were generated during the Stillwild hackathon upgrade with the built-in OpenAI image generation tool. They depict imagined environments, not photographs of real places. The originals are retained; the project uses copies under `public/art/`. Both source images are **1672 × 941**. A **3840 × 2160 export** is a larger rendered output canvas, not a claim that these raster sources have native 4K detail. Interactive lighting, weather, foreground objects and sound are implemented by Codex inside Asyncly.

## Natural conservatory

Project asset: `public/art/natural-conservatory.png`.

Prompt:

> Use case: photorealistic-natural. Create an original professional 16:9 landscape desktop wallpaper environment for Stillwild, an artistic living-wallpaper studio. Target high-resolution 3840x2160 composition if supported. A serene temperate forest conservatory at first light, naturalistic fine-art landscape photography, subtle atmospheric depth, layered mature ferns and elegant botanical branches at the far edges, a quiet shallow reflective pool across the lower third, distant soft forest silhouettes. The focus is composition and real material texture: individual fine frond veins, weathered stone, velvety moss, slight humid haze. Warm sunlit opening in the upper-right, soft forest greens and mineral neutrals, sophisticated restrained color grading, no HDR look. Keep the left and central upper half calm with spacious softly gradated mist so desktop icons stay readable; don't fill every area. Delicate light shafts should be subtle enough for a separate procedural lighting overlay; leave a believable neutral base for daytime and moonlit grades. Wide uninterrupted scene, cinematic framing, realistic perspective, gallery-quality tranquil artwork. No text, watermark, logos, borders, UI, people, animals, cartoon clouds or fantastical giant objects. This is a reusable background layer, not a website mockup.

## Future nocturne

Project asset: `public/art/future-nocturne.png`.

Prompt:

> Use case: stylized-concept. Create an original professional 16:9 landscape desktop wallpaper environment for Stillwild, a living-wallpaper studio. Target high-resolution 3840x2160 composition if supported. A sophisticated cinematic futuristic nocturne: a quiet dark mineral landscape around a mirror-smooth shallow lake, one sculptural brushed-metal orbital arch rising in the right half, distant architectural planes disappearing into atmospheric fog. Subtle cyan-teal edge illumination with tiny amber accents, graphite, deep petroleum green and cool silver materials. A faint luminous auroral veil in the high sky, starless quiet negative space over the left and upper center for desktop icons. Carefully composed futuristic fine art, believable physically shaded surfaces, delicate reflections, restrained luminous edges, sophisticated film lighting and granular material detail. Mature gallery artwork; not a videogame splash screen, not a purple neon cyberpunk city. Dynamic particles, aurora and rain will be added procedurally later, so do not bake in obvious streaks, bright lens flares or large particle clusters. No text, logos, watermarks, borders, UI, characters, spaceship, cartoon clouds, busy iconography or illustration outlines. This is an environment backplate, not a webpage mockup.
